# Walmart Sales Analysis & Dashboard

## 📊 Project Overview

An end-to-end **Walmart Sales Analysis project using Microsoft Excel**.

In this project, data from multiple files was cleaned and merged into a single dataset. Excel functions such as **VLOOKUP** were used for data merging and analysis. The final data was analyzed using Excel and presented through an interactive dashboard.

## 🔄 Project Workflow

**Data Cleaning → Data Merging → Excel Functions → Data Analysis → Data Visualization → Dashboard Design**

## 🛠️ Tools & Techniques

- Microsoft Excel
- Data Cleaning
- Data Merging
- VLOOKUP
- Excel Functions
- Pivot Tables
- Pivot Charts
- Slicers / Filters
- Data Analysis
- Data Visualization
- Dashboard Design

## 📈 Dashboard Highlights

The dashboard provides an overview of Walmart sales performance through:

- Total Orders
- Total Quantity
- Average Discount
- Total Revenue
- Total COGS
- Total Profit
- Sub-Category-wise Revenue
- Revenue Trend Analysis
- Category-wise Revenue Distribution
- City-wise Revenue
- State-wise Revenue
- Made-In-wise Revenue Distribution

The dashboard also includes interactive filters for:

- Gender
- Order Status
- Payment Mode
- Occupation
- Rating
